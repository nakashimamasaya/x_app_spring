# Architecture Decision Records

「なぜそうしたか」を残す場所。**何をしたか**はコードと git 履歴に書いてある。ここに書くのは
**他の選択肢を捨てた理由**と、**どうなったら見直すか**。

## 書くタイミング

- 選択肢が複数あり、どれを選んでも動くが、後から変えるのが高くつく判断をしたとき
- 一見遠回りに見える方法を意図的に選んだとき（後任が「なぜ普通にやらないのか」と思う箇所）
- Renovate の Dependency Dashboard で **major 更新を承認したとき**

## 書式

`NNNN-短い題名.md` の連番。テンプレートは以下。

```markdown
# NNNN. タイトル

- ステータス: 採用 | 見直し中 | 破棄（NNNN で置き換え）
- 日付: YYYY-MM-DD

## 背景
どういう状況で、何を決める必要があったか。

## 決定
何を選んだか。

## 理由
なぜ他ではなくこれか。捨てた選択肢と、捨てた理由。

## 結果
これによって何が楽になり、何を諦めたか。

## 見直す条件
どうなったらこの決定を再検討するか。
```
